# READ ME
### This is only a prototype how to make a python.exe with version update

## INSTALLATION
> For Window
- pip install pyinstaller
- python -m pip install pyinstaller (vnev)
> For Linux/Ubuntu
- pip3 install pyinstaller
- python3 -m install pyinstaller (venv)

## DESKTOP WRAPPER
> venv in vscode

 pyinstaller calculator.py --onefile --noconsole --icon=icon_name.ico
